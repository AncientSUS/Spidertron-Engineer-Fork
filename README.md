Spidertron Engineer 2.0 Fork

Unofficial community-maintained fork of Spidertron Engineer for Factorio 2.0.

Original mod created by Xorimuth.

This fork updates the mod for compatibility with Factorio 2.0 and modern Spidertron-related dependencies.

Current Status
Compatible with Factorio 2.0
Updated for modern Spidertron Enhancements versions
Basic gameplay functionality restored
Prototype and settings compatibility issues fixed
Known Limitations
Space Age compatibility has not been fully tested
Multiplayer compatibility has not been extensively tested
Some edge cases or hidden bugs may still exist
